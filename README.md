## What you can do with it
- Organize your profile
- Add photos to your profile
- Find other people
- Like and write messages to them
- Find a love of your entire life!


## Technologies used:
- ASP.NET Core
- ASP.NET Core MVC
- Angular
- Entity Framework
- SignalR
- MS SQL Server
- Azure
